# Expenzo 💸

A personal project I built to practice full-stack web development. 
Expenzo lets users track their daily expenses, set budgets, and 
visualize their spending — all saved to their own account.

## 🌐 Live Site
[expense-8xsq.onrender.com] (https://expense-8xsq.onrender.com)

## Why I Built This
I wanted to go beyond simple console projects and build something 
real that I could actually use. This taught me how authentication, 
databases, and deployment all connect together.

## What It Does
- Sign in with Google or create an account with email/password
- Add and delete transactions with categories
- Track budgets with visual progress bars
- See your spending broken down in charts
- All your data is saved and private to your account

## What I Used
- **Python & Flask** — backend and routing
- **SQLAlchemy** — database models
- **PostgreSQL** — stores all user data in production
- **Chart.js** — spending visualization charts
- **Google OAuth 2.0** — Sign in with Google
- **Render** — where the app is hosted live

## What I Learned
- How to build and deploy a full-stack web app from scratch
- Setting up Google OAuth and secure user authentication
- Connecting a live PostgreSQL database on Render
- Using Chart.js to turn raw data into visual charts
